    Open API & Interoperability Layer

    Every dataset in Land Stack — RoR, registration, planning, fiscal, utility — is exposed through the same versioned REST API, so departmental systems and citizen apps read the parcel exactly as the registry holds it. Pick an endpoint to preview a live response for the parcel currently open in the dossier.

    Security & governance (per problem statement)
    • OAuth2 / API-key authentication, scoped per department & role (Citizen / Officer / Admin, as selected above)
    • Role-based access control on every write endpoint (mutation, permit, tax)
    • Every read/write is appended to the immutable audit trail shown on the Admin Dashboard
    • Standardised metadata: ULPIN as common key, ISO-aligned date/geo formats across all States/UTs
